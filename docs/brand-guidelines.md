# Homies のブランド・UI方針

- マスコットの犬の名前は「ホミー」。王冠などのバリエーションも同じキャラクター。
- ユーザー提供のホミー素材（assets/images/mascot）を使用する。
- 基本色は白・黒・ブルー・ライム。追加したピンク、ラベンダー等のパステル配色は使用しない。
- タブの選択背景はライムで統一する。
- 投稿は背景に直接載せるフラットな表示。外枠の角丸・影は付けず、細い区切り線で分ける。
- クイックマッチの入口はマッチング画面上部のホミー付きバナー。右下の独立した雷ボタンは表示しない。
- クイックマッチは参考画像の2列×3行のジャンル選択と青い開始ボタンを踏襲。中央は王冠のホミーを使う。
