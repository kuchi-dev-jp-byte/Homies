# Homies

学校生活と、新しいつながりをひとつに。Expo + React Native の操作可能な **Phase 1 UIプロトタイプ**です。ユーザー提供のUI画像を参照して、白・ラベンダー・青紫、学校生活の情報カード、一体型タイムライン、プロフィールの一覧／カード表示を実装しています。

## 起動

Node.js 20.19.4以上（20.20.2で検証）。依存関係はインストール済みです。別環境では `npm ci` を実行します。

```sh
npm run web       # Expo開発サーバー（Web）
npm start         # QRコード付きExpoサーバー
npm run ios       # iOSシミュレーターへ起動（対応するExpoクライアントが必要）
npm run android   # Androidエミュレーターへ起動（対応するExpoクライアントが必要）
```

Expo SDK 55に固定しています。端末のExpo GoがSDK 55に対応しない場合は、Xcode / Android Studioを用意し `npx expo run:ios` / `npx expo run:android` で開発用ネイティブアプリを作成してください。署名・配布用ビルドは未作成です。

ビルド済みWebの確認（Python 3が必要）：

```sh
npm run build:web
npm run preview
# http://localhost:8083
```

プレビューは127.0.0.1のみで待ち受けます。詳細URLの再読み込みにも対応します。Expo開発サーバーのWatchmanが停止する環境では、このビルド済みプレビューを利用できます。

## 画面と機能

| 画面 | 操作 |
| --- | --- |
| ホーム | 時間割・提出物・学校連絡の詳細、学校連絡／掲示板／生徒投稿の3種類のフィルター、学校／掲示板／生徒投稿、おすすめ接点 |
| マッチング一覧 | 共通タグによるルールベーススコア、興味カテゴリ・学年・クラス・部活・やりたいことの絞り込み、プロフィール遷移 |
| マッチングカード | 一覧と共通の候補、重なった次候補、左右スワイプ、スキップ／気になるボタン、次候補へのアニメーション |
| 投稿作成 | 生徒／掲示板の切替、タイトル、本文、写真選択、カテゴリ、タグ、公開範囲、募集人数・締切、Zodの入力検証 |
| 投稿詳細 | コメント、いいね、保存、投稿者プロフィール、参加希望、関連コミュニティ |
| コミュニティ | 参加中／おすすめ、最新メッセージ付きルーム一覧、吹き出し型トーク、メッセージ送信・下書き保存、参加／退出、ノート、メンバー一覧 |
| マイページ | プロフィール、保存（投稿／人の切り替え）、気になる相手、自分の投稿、所属コミュニティ、本人専用設定 |
| プロフィール詳細／編集 | 写真、名前、自己紹介、タグ、得意なこと、やりたいこと、関連投稿／コミュニティ |
| 通知／学校情報／設定 | 通知の既読化、提出物の完了切替、デモデータ初期化、通報のローカル記録、ユーザー非表示 |

コミュニティはオープンチャット型UIです。グループトークの送信はローカル保存で、他の端末への配信、既読、リアルタイム同期は未実装です。サンプル会話の日時は固定です。

操作はAsyncStorageに保存します。Webでは同じオリジンのブラウザストレージを使用するため、ポートが変わると別のデモデータになります。投稿作成フォームの入力途中は永続化しません。ルームごとのチャット下書き・送信済みメッセージは永続化します。画像選択後のネイティブURIは端末の一時キャッシュで、長期保存はStorage接続フェーズで対応します。

学校生活の日付・天気・投稿時刻・リアクション／コメントの初期件数は、参考画像に合わせた固定フィクスチャです。初期コメントの本文は作成しておらず、詳細画面にはこの端末で追加したコメントを表示します。コミュニティの人数もデモ用総数で、メンバー一覧には架空プロフィールのみを表示します。

「気になる」は本人の保存リストへの追加です。相手に一方的なDMや通知は送信しません。リセットは「設定 → デモデータをリセット」から行えます。

## 構成

- `app/`: Expo Routerの画面と5タブ
- `src/components/`: 配色・共通UI、投稿カード、フォーム
- `src/features/`: 学校生活、マッチング、コミュニティ、プロフィール
- `src/data/`: 型定義、モック、画像解決、データ取得インターフェース
- `src/lib/`: マッチング／公開範囲／バリデーション、Query hooks、Supabaseクライアント生成関数
- `src/store/`: Zustand + AsyncStorageのローカル操作・永続化
- `assets/images/`: 同梱デモ写真
- `docs/database-design.md`: PostgreSQLテーブル、RLS方針、招待／所属確認、Storage、検証項目
- `docs/verification.md`: 実施済み検証と残課題

NativeWind 4の共通レイアウトとReact Nativeスタイルを併用。Reanimated 4 / Gesture Handlerをカードの操作に使用。発見データはTanStack Query、端末内操作はZustandに分離しています。Supabaseの接続キーは `.env.example` を参照してください。環境変数を設定しても自動的に実運用へ切り替わりません。

## 検証コマンド

```sh
npm run typecheck
npm run lint
npm run test
npm run build:web
npx expo install --check
npx expo export --platform ios --platform android --output-dir /tmp/homies-native-export
```

主要依存は正確なバージョンで固定し、`package-lock.json` を含めています。ZustandのESMをExpoのWebバンドルで動かすため、Babelの `unstable_transformImportMeta` を有効化しています。Babel設定変更後は `npx expo start --clear` または `npm run build:web -- --clear` でキャッシュを破棄してください。

## 写真素材

写真はUnsplashのイメージ素材を同梱。架空プロフィールの名前・学年・学校との関連はありません。素材URLは `src/data/mock.ts` と `assets/images/ATTRIBUTION.md` に記録しています。ユーザーの参照画像自体はアプリに埋め込んでいません。

## 2026-11-10 追加機能

- 学校 → 先生からの宿題：通知作成、提出期限、ミマシタヨ！、先生側の確認表示。画面上部の「先生／生徒」は端末デモ用の役割切替。
- 相互マッチ：「気になる」が双方で一致すると成立。マッチングの「マッチした相手」に一覧表示。下部のデモ設定で相手側の反応を再現できる。取り消し・ブロックを即時反映し、既存の保存状態を維持する。
- 生徒の1日制限：日本時間の当日投稿で判定。未投稿はカード操作3回、投稿済みは20回。回数は保存され、候補リセットでは回復しない。流行とトランプは当日の投稿で解放。翌日未投稿なら再度制限。
- 流行：直近7日の公開投稿のタグ・ハッシュタグ別投稿数と、前の7日との差で集計。匿名・学校連絡は対象外。端末にある投稿のみで、学校全体やインターネットの実流行ではない。
- 匿名つぶやき：投稿・タグ・コメントの禁止表現チェック。公開カードと投稿詳細から投稿者プロフィールへのリンクを除外し、他人の公開プロフィールにも匿名投稿を出さない。投稿者IDは管理用に保持。ローカルデータ自体は暗号化匿名化していない。
- トランプ：ブラックジャック、52枚の山札、Aの1/11、バースト判定、ディーラー17ルール、日別得点とサンプル順位。勝利100点／引分30点。金銭・景品なし。プレイ中の手札と得点を端末保存。
- ノート：60文字・24時間表示。自分のノート編集・保存と、相手のサンプルノート表示。
- インスタント：カメラ／写真選択、24時間公開、受信者1回10秒の閲覧。撮影した写真は自分の端末に保存し、実ユーザーへの配信はない。「受信サンプルを追加」で受信側UIを試せる。

インスタントはiOS/Androidでexpo-screen-captureの保護を有効化してから表示する。バックグラウンド移行時は写真を隠す。Webはスクリーンショット防止を保証できないため、写真そのものを表示しない。新しいネイティブモジュール・カメラ権限を含むため、`npx expo run:ios` / `npx expo run:android` で再ビルドする。実機での保護・撮影・閲覧タイマーのQAは未実施。画面を別のカメラで撮る行為などは防止できない。

禁止表現は初期辞書と正規化による簡易フィルター。あらゆる悪口・隠語・文脈を完全に判定するものではない。本番ではサーバー側の検査、通報受付と管理者審査を必須にする。端末内の役割・利用回数・順位・時刻はサーバーによる保証がなく、本番の権限・不正対策の代用にはならない。

宿題通知、既読、ノート、インスタント、相互マッチ、ランキングの他端末との同期、Push通知、学校全体の集計とサーバー側検証は未実装。Supabase接続・学校認証は引き続き次フェーズ。

## 2026-11-10 画面と交流機能の更新

- ホームの毎日利用案内を削除。検索・トレンドを下部タブへ追加し、学校を中央に配置。
- マッチングはカード／マッチした相手の2区分。カード画面上部の表示切り替えボタンで一覧へ移動。カテゴリ列と下部操作ボタンを削除し、カードを拡大。左右スワイプを使用する。
- トランプはコード・得点を保持したまま停止。入口を削除し、直接URLも休止画面に限定。ストアの開始・進行操作も無効化。
- プロフィールの友達申請、受信申請の承認、承認後のチャット自動追加。気になる操作も自動で友達申請。双方が気になる場合は相互申請の承認として友達に追加し、マッチも成立する。既存の3会話は承認済みサンプルとして保持。
- 新しいマッチはタブとマッチ一覧セグメントに赤丸。マッチ一覧を開くと既読。
- ベルの隣のハートはアクティビティ一覧。リアクション・マッチ・友達申請・承認を保存する。相手の操作はアクティビティ下部の明示されたデモ設定で再現できる。実通知の配信は未接続。
- プロフィールはXのカバー画像・丸型アイコン・自己紹介・投稿／メディア／紹介タブを参考に再構成。不要な個人情報の入力項目は追加していない。
- インスタントは撮影専用。ギャラリー追加を撤去し、撮影→確認→承認済み友達へのシェアという操作に変更。Webは撮影と保護付き閲覧を提供しない。ネイティブカメラ・実際の配信はそれぞれ実機QA・バックエンド接続が必要。
- シークレットモードは承認済み友達限定公開。流行の集計から除外。アプリのフィルターのみのため本番RLSには未対応。
- トレンドは全体／男子／女子で絞り込み。任意の集計用属性をプロフィール編集で設定。未設定のユーザーは全体のみ。名前や写真から推定しない。サンプルプロフィールに男女の属性を勝手に割り当てていない。
